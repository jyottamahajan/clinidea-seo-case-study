## 🛠️ SEO & Technical Implementations

### 1. 🔍 On-Page SEO & Metadata Strategy
* **Keyword Mapping:** Structured high-intent keywords targeting clinical research courses (e.g., *Clinical Data Management, Pharmacovigilance Course, Medical Coding Training*).
* **Dynamic Meta Tags:** Implemented unique, click-optimized `title` and `meta description` tags across all core landing pages.
* **Semantic Hierarchy:** Ensured a strict `H1 -> H2 -> H3` heading structure for optimal content indexing.
* **Social Graph Optimization:** Configured Open Graph (`og:*`) and Twitter Card tags for high-engagement link previews.

### 2. ⚙️ Technical SEO & Crawlability
* **Automated XML Sitemap:** Built a custom Node.js script (`generate-sitemap.cjs`) that automatically maps all static & dynamic course routes on build.
* **Robots.txt & Canonical Tags:** Configured strict crawling rules and canonicalization to avoid duplicate content penalties.
* **Instant Indexing (IndexNow Protocol):** Integrated automated API scripts to ping search engines immediately whenever content or routes are updated.

### 3. 🧩 Structured Data (Schema.org JSON-LD)
Implemented custom JSON-LD schemas validated on **Google Rich Results Test**:
* **`EducationalOrganization` Schema:** Establishes brand authority, social profiles, and contact points.
* **`Course` Schema:** Delivers rich course snippet cards (duration, syllabus, provider) directly in Google SERP.
* **`FAQPage` Schema:** Maximizes SERP pixel real estate with collapsible FAQ accordion rich snippets.
